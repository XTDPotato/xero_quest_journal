# 关联任务生成与模板库

**简体中文** | [English](en/generation-and-template-library.md) · [文档中心](README.md)

以下功能属于本地开发构建，已有 GitHub Release 不会自动包含这些改动。

## 首次选择与命令

每位玩家第一次进入一个世界，收到任务数据并进入游戏后，会显示生成方式选择。
打开界面不会创建任务。选择取消或开始生成后，选择状态记录在该世界的玩家数据中；
再次进入不会反复弹出。未作选择就断开连接时，下次进入仍会提示。

```text
/xero_quest start_generate_gui
/xero_quest locate <id>
```

第一条命令重新打开选择界面，普通玩家也能查看；实际生成共享任务定义要求管理员权限，
或当前单人世界的所有者。多人服务器普通玩家不能通过此界面修改全服任务。
第二条定位指定的结构任务：任务必须可追踪且已解锁；已经追踪时可直接重试定位。

| 生成方式 | 行为 |
| --- | --- |
| 溢想模式 · 模组进度链 | 保留模组进度的前置关系，按实际完成条件关联材料和配方任务 |
| 溢想模式 · 结构探索线 | 从当前世界可生成的结构及维度创建串联探索任务 |
| 溢想模式 · 进度链与探索线 | 生成上述两类任务，并把同模组探索入口接到进度里程碑之后 |
| 传统模式 · 全部内容任务 | 沿用原来的进度、物品及战斗任务生成器 |

可选择所有内容或指定命名空间；“包含进度条件关联的配方与材料任务”控制是否加入配方支线。
生成在后台规划和保存，结果显示在聊天栏。重跑会保留已有任务文件、ID、作者编辑和玩家进度。
跨模组配方引用会一起规划，校验前置关系后发布，避免按模组保存顺序丢失后面的引用。
保存过程中验证失败会回滚本次写入的文件。

## 奖励与关联范围

进度任务的奖励从后续进度条件涉及的配方中选择少量材料，最多四种；
避免直接发后续目标成品。配方支线奖励也面向下一个制作步骤。
无法确认相关奖励时保留空奖励，作者可继续编辑；不会把无关经验作为通用填充。
结构探索奖励提供食物、火把等后续旅途补给。

首版优先读取有展示信息的模组进度及其前置，识别 `minecraft:inventory_changed` 条件里的显式物品 ID，
关联常规配方和生存可达材料。模组专用条件、动态机器配方、脚本阶段及无法读取的条件不会被猜测成已支持的机制。
需要专用 API 的内容仍需后续适配器；本轮使用数据包进度夹具验证跨命名空间关系，未宣称逐个验证所有第三方模组。

## 结构定位与共享

追踪含结构地点条件的任务时，服务端排队定位；任务详情中的“定位目标结构”按钮也可重试。
定位成功后显示实际坐标标记，V 播放已有的坐标指引。任务按进入结构范围判定完成，
定位点优先采用结构首个片段内部位置，避免标记在结构范围外。

结果按任务、地点目标和队伍保存到世界数据，在线队友共享同一目标；重连会同步缓存，
不会每次追踪都重新寻找。`globe.located_structure` 同时保留结构 ID、维度和坐标供节点使用。
切换维度的任务需要先进入目标维度。找不到目标会提示，并可移动到其他区域后重试；
不会伪造坐标。定位仍在服务端执行有半径上限的原版结构搜索，并设冷却及排队，可能发生短暂区块计算。

## 获取模板与分组

主线、传说、委托、世界任务分类各新增“获取任务”模板：默认获取 16 个橡木原木，
条件为 `item_hold`，达到数量自动完成，物品保留，不出现提交按钮。
与累计采集条件 `item_acquire` 不同，持有模板会把已有库存也计入数量。
创建时可在条件编辑器更换物品、数量或改成累计获取。

模板选择界面底部“添加模板”左侧的图标按钮用于添加模板组。空组也会保存并显示，
组属于模板库，不会创建外面的任务组。选中组后添加模板会继承该组。
编辑模式长按约 350ms 后拖动模板或组进行排序，松开才保存；拖到组标题可调整归组，
拖到其他模板前后可排序。快速拖动仍用于滚动，边缘支持自动滚动，Esc 取消本次拖动。
模板顺序、组及归属由服务端保存到 `config/xero_quest/template_library.json`，通过任务目录同步。

任务界面左侧原有长按排序继续可用。右键“移动任务位置”可以连续上下移动，
用完成按钮、Esc 或右键退出；已修复移动后历史版本未更新导致每 tick 重建界面、输入卡住及 tooltip 闪烁。

## 拾取与提交提示

提示默认逻辑宽度缩为 320，普通字号时每行 30、标题 20；最多四条、最新优先。
预览和实际提示使用同一尺寸计算，字号增大时扩展必要高度，名称过长会裁切。
追踪任务的获取、持有或提交条件匹配时，拾取/制作/熔炼事件显示相关物品及任务进度。
手动提交成功并实际扣除物品后显示“已提交”；不足或失败不会产生成功提示。
通知包含对应任务 ID、动作类型、数量和进度；每条新通知保留独立的入场动画时钟，
重复获得同一物品也新增一条。动画预览依次展示四行进入，播放一次后停止。

设置 → 通知 → 提示布局支持位置、整体大小、独立字号、任务背景及动画，
小地图避让区域可拖动位置和角落手柄改尺寸，宽高也能数值输入。
顶部栏缩短、底部固定色带移除；小窗口属性区使用平滑滚动。

