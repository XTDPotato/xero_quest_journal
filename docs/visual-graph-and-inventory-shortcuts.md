## 节点画布快速编辑

- 双击节点内的代码块或长文本块，打开相应编辑器。JS 判断进入带 JS 参考的脚本编辑器；命令、值和邮件正文进入多行编辑器。
- 编辑器先保留草稿；保存后更新节点草稿，仍需保存事件图及所属任务。取消不修改节点。
- “全部显示”默认勾选，节点正文会按宽度换行且保留换行。取消勾选时仅折叠画布预览，不截断保存的值。重新勾选可查看原内容。
- 点可视化判断节点的字段槽、比较符或逻辑项，会弹出快速选择菜单。菜单即时过滤，并按字段中文名称匹配拼音、拼音首字母。点槽旁的期望文本可直接修改常量。
- 右键同一选项打开完整可搜索选择器，适合查找和比较较长的字段/变量目录。右键菜单中的值可搜索其中文标签与拼音。
- 长按字段槽约 300ms 后拖出，可生成对应的只读“玩家/世界变量”节点。短拖仍保持节点选项原状；点击节点其他区域照常移动节点。提取后可拖入变量设置节点的输入区。
- 设置变量节点既能接收自定义变量，也能接收游戏变量。游戏变量会自动转换成匹配的玩家/世界设置节点；不可修改的派生字段只能拿来比较，不能写入。

## 玩家变量的所属对象

玩家字段的值从玩家或实体选择器读取。事件图可视化判断在左值与右值字段各自展示目标玩家/选择器，默认 `@s` 表示触发事件的玩家。

- `@s`：触发事件的玩家。
- `@p`：执行上下文中的最近单个玩家。
- 玩家名称、`@a[name=...]` 等能确定**单个玩家**的选择器。
- 不允许读取目标集合不确定的 `@a`、`@e`；命令动作可以有多目标语义，但字段比较必须有唯一数值来源。
- 自定义变量保留自己的任务/全局作用域，不套用玩家选择器。
- `eventType`、`eventTarget` 是本次事件值，不按另一个玩家的属性值重读。

玩家经验等级、生命值、最大生命值、饥饿、坐标、潜行和疾跑可由设置变量节点写入；天气/时间字段写入世界。`playerName` 与 `playerId` 可比较但不可写入。节点会校验选择器、字段归属与数值范围，保存后的服务端仍会再次校验。

## 数值、文本与队伍共享变量

- 变量创建时选择“数值”或“字符串”。旧变量根据初始值自动推断；数值变量只接受有限数字，类型和共享归属创建后固定，如需改变请新建变量。
- 变量归属选择“当前玩家”或“队伍共享”。队伍共享使用 Minecraft 记分板队伍；不在队伍中的玩家使用自己的私有值。共享值保存在世界数据中，离线后仍保留。
- 任务图可读取三个只读进度值：`<任务ID>.progress_current`、`<任务ID>.progress_required`、`<任务ID>.progress_ratio`。进度显示控件的 `displayText` 属性可用文字或变量设置名称，同时保留 `当前 / 需要` 数字。
- “计算变量”节点会更新一个数值变量。操作菜单可搜索，支持加、减、乘、除、取余、乘方、最小/最大值、`atan2`、`sin`、`cos`、`tan`、反三角函数、平方/立方根、绝对值、取整、对数、指数、符号及角度转换。三角函数输入为弧度；侧栏即时显示表达式、预览值和错误状态。预览使用已同步值，尚未同步时使用初始值；服务器执行时会重新计算和校验。
- 二元运算可切换常量/变量输入并从变量选择器选取数值变量；一元函数自动隐藏操作数输入。除零、非法定义域、非数值操作数和非有限结果都会拒绝写入。
- 字符串变量不能作为计算目标或数值运算数；可通过“设置变量”节点写入文本，或在 `displayText` 等文本属性绑定。
- 定位结构节点默认保存到队伍共享的 `globe.located_structure` 字符串变量。其值是结构化 JSON，含 `kind`、结构 `target`、`dimension` 和 `x/y/z`；同时自动填充 `globe.located_structure_id`、`globe.located_structure_dimension` 与三个数值坐标变量。定位成功还会沿用任务坐标追踪与地图标记。
- 内置示例模板：`tutorial_progress_label` 演示 0/4 任务进度名称由节点图修改；`tutorial_shared_locate` 演示定位平原村庄、自动追踪并把结果存入队伍共享结构变量。

建议先插入“计算变量”节点，再将 `globe.located_structure_x` 等坐标变量接入比较、传送或后续节点。服务器执行时仍会重新检查变量类型、任务归属、队伍共享策略与数值边界。

## 物品栏入口

游戏“背包”与“创造物品栏”可分别显示任务和邮件入口。两者使用独立开关、独立锚点与偏移，不会互相挪动。

在设置 > 常规开启入口，再点“物品栏入口位置”编辑：

- 预览区按屏幕可用尺寸缩放显示物品栏和两个入口，可直接拖动。
- 锚点为屏幕九宫格：左上、中上、右上、左中、屏幕中心、右中、左下、中下、右下。
- 偏移相对于所选锚点的对应按钮左上角；左上锚点的零偏移即屏幕 GUI 坐标 `x=0, y=0`。
- 靠近锚点会自动吸附。按住 Shift 拖动可以关闭吸附；箭头微调单位为 1，Shift+箭头为 10。
- 直接输入有符号偏移可将入口放到锚点内外任意位置；屏幕裁切只在显示时限制，保存的锚点和偏移仍保持不变。
- 取消返回原设置；保存写入 `config/xero_quest/ui/client.json`。

## 配方查看器与 REI 收藏入口

安装 EMI、JEI 或 REI 时，背包不再叠加旧版书本/纸张物品按钮，改为使用本模组的任务旗标与邮件信封图标，
图标可见像素尺寸均为 16×16；位置仍由两个独立的锚点/偏移设置控制。

安装与游戏版本匹配的 REI 后，REI 收藏区域另会出现 16×16 任务旗标和邮件信封，
点击分别打开日志或邮箱。REI 原生收藏栏可拖动排序/移除；设置 > 工具 > “管理 REI 物品栏入口”
可重新添加或移除任意入口。REI 独立保存收藏；无 REI 时此管理入口和 REI API 均不会加载。

发布包不捆绑 JEI、EMI、REI、Architectury 或 Cloth Config；
玩家应按当前整合包自行安装相容版本。1.21.1 REI 收藏功能与真实客户端联测，
1.20.1 的 API 按 REI 12 编译并与旧加载器共存检查。JEI/EMI 使用本模组的 16×16 背包入口，
不注册原生 JEI/EMI 收藏类型；REI 收藏快捷条目仅在 REI 存在时显示。
