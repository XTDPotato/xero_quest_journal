# 任务修改、删除的撤销与重做

[使用指南](guide.md) · [界面图鉴](interface-gallery.md)

任务编辑模式左下角的撤销、重做图标现在能恢复已保存的任务操作。
悬浮可查看下一步操作类型及可用步数。

| 操作 | 入口 |
| --- | --- |
| 撤销最近一步 | 左下角撤销图标，或 `Ctrl+Z` |
| 重做最近一步 | 重做图标、`Ctrl+Y` 或 `Ctrl+Shift+Z` |

输入框获得焦点时，按键交给输入框处理，不会意外恢复整份任务。
先保存或取消当前表单，再执行任务级撤销。

## 可以恢复什么

- 已保存的任务属性、描述、图标、完成条件和奖励定义。
- 任务源码、控件、事件节点图与画布尺寸的保存。
- 单个或批量删除任务，以及删除任务组。
- 删除时同时改动的其他任务前置关系与章节任务引用。
- 新建、复制和粘贴任务；一个批次作为一步处理。
- 章节编辑、解锁关系、任务排列和保存的任务模板。

撤销删除会将原文件和关联引用一起恢复；重做会重新应用该批操作。
恢复后的任务会重新选中，便于核对。初始化默认控件和窗口大小适配不会单独占一步。
系统界面布局仍使用原有本地布局撤销。

## 保存范围

历史由服务端按编辑者独立保存，当前完整作者编辑入口限本地集成服务器。
关闭再打开任务界面、进入条件/奖励/源码等子编辑器，不会清除历史。
最多保留 64 步，通常还受约 32 MiB 文本预算限制，较早操作会被淘汰。
一个特别大的批次至少保留其最后一步。退出世界或重启后不保留此撤销栈；
批量操作原有的磁盘备份仍在 `config/xero_quest/history/`。

成功进行新的编辑，会清空重做分支。未通过校验的修改不占历史，也不会清空重做。
已有旧版操作不会自动补录。

## 冲突与玩家进度

撤销和重做都需要管理员编辑权限。每次恢复之前，会核对所有相关文件是否仍与
这一步完成后的内容一致。若被外部编辑器或其他作者修改，整步拒绝恢复，
不会用旧快照覆盖新文件，也不会只恢复一半。

恢复改变的是任务定义文件。玩家的完成记录、计数、冻结奖励、已经发出的物品、
经验和邮件不随之回退，避免撤销界面编辑造成重复领奖。
变量运行值、进度重置、发放奖励等游戏动作不属于任务文件撤销。

## 验证

`creationTest` 增加真实任务文件回归，包括：
属性/条件/奖励/源码和控件恢复、新建与模板恢复、批量删除及引用恢复、
文件冲突时无部分写入、权限拒绝、玩家进度保持、按钮/三种快捷键、
关闭重开界面后恢复删除。

画布范围专项使用：

```powershell
.\gradlew.bat runClient -PcanvasEditorTest -PcanvasHistoryOnly
```

此参数仅验证画布坐标、缩放、尺寸保存和撤销/重做，不包含后续源码或结构预览。
