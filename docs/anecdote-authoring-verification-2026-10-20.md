# 逸闻编辑与奖励页复验

验证日期：2026-10-20。这里记录本地未发布改动；GitHub 的既有 0.2.2 Release 附件不包含本轮更新。

## 客户端

Java 21，NeoForge 1.21.1，真实客户端与集成服务器：

- `runClient -PanecdoteAuthoringTest`：通过。拖动位置/宽/高/比例、数字属性/字号、撤销重做、
  JSON 旧字段默认、保存与客户端快照回读、记录列表翻译/关闭、四列十枚贴纸及满页清空状态、
  新记录续播、服务端领取 50 个钻石与重复领取拒绝、记录存档保留。
- `runClient -PanecdoteUiTest`：通过。总览入口、默认图标、新建/奖励/记录入口、
  按压松开选择、关书动画与奖励入口。跳过通知横幅播放阶段。
- `runClient -PruntimeTest`：任务筛选勾形修复后通过，保留已选中状态的实际截图。
- 图标选择器检查逐帧滚动推进及未变化项目的 tooltip 对象复用，PNG 检查非透明像素；
  额外检查 1920×1080 与 854×480 的编辑布局截图。

未在本轮重新运行所有历史功能与所有第三方模组组合。

## 数据与领取

每条逸闻的 `cardLayout` 独立持久化。更新记录或奖励保留外观。
贴纸按完成时间稳定排序，每十条构成一个批次；清页只改变显示，不删除历史。
每批奖励由第十条记录所属条目配置，使用现有任务奖励的服务端执行和领取回执。
奖励在首次领取尝试时冻结，定义修改不会覆盖已经建立的领取回执。
需要手动选择的战利品奖励可能返回 `choice_required`；当前里程碑按钮没有新增自选奖励选择流程。

## 素材

所有新增书册/图标素材为 PNG，路径与分辨率列于 [逸闻文档](anecdotes.md#png-素材目录)。
地图水印来自用户提供的局部参考图，提取为透明图片；绘制脚本会保留此文件。
本轮修复过透明图标生成问题，并增加非空像素校验。

## 构建

共享源适用于 Forge/Fabric 1.20.1 和 NeoForge/Fabric 1.21.1。
四个目标的本轮生产构建均通过，JAR 继续低于 5,000,000 字节限制。
1.20.1 使用 Java 17，1.21.1 使用 Java 21。Loom 工程应串行构建，避免映射缓存重建冲突。
26.x 完整移植状态不因本轮更新而改变。
