# 中文界面图鉴与操作参考

[项目首页](../README.md) · [安装与版本](porting-matrix.md) · [全部命令](commands.md) · [JS 参考](javascript.md) · [发布验证](release-verification-2026-10-16.md)

本页展示实际 Minecraft 客户端界面。图片全部为原生 **1920×1080、简体中文**，
不使用放大截图或局部裁剪替代全屏图。2026-10-16 的新增图来自 NeoForge 1.21.1；
四个已完成平台复用这些界面源码，平台测试范围另见发布验证。
截图中的示例任务、邮件和战利品用于演示，不代表安装后自动发放奖励。
点击图片可查看原尺寸。个别资源 ID、源码、测试名称保留英文。

## 1. 任务日志与奖励

入口：`J` 或 `/xero_quest open journal`。左侧为分类、任务组和任务列表；
右侧为当前任务的标题、目标、进度、说明及底部奖励。
选中任务会保存，下次打开继续显示该任务。

![任务日志、目标进度与底部奖励](images/journal-current-zh-1920.png)

完成条件满足但未领取奖励时，任务仍保留在进行中，列表最右侧显示领取图标。
领取后再进入已完成分类。新任务未读与奖励领取是不同状态。
底部的奖励卡片显示数量和品质；品质只改变展示，不修改真实物品属性。

作者模式中右键任务行可打开带图标和分组标记的菜单，
包括任务属性、条件、关系、复制和进度管理。危险操作与普通编辑分组展示。

![任务右键菜单、图标和分组](images/task-context-menu-zh-1920.png)

任务属性表单配置名称、图标、分类、说明和行为开关。修改草稿后保存；
来源 ID、任务内容和世界中的玩家进度分别管理。

![任务属性编辑](images/task-properties-zh-1920.png)

![领取奖励时的收据弹窗](images/reward-receipt-zh-1920.png)

奖励编辑入口：作者模式下的任务菜单 → 奖励。每项可选择奖励类型、物品或动作、
数量和物品品质；按保存提交草稿。奖励脚本应使用奖励用途的 API，不能与条件脚本混用。

![奖励编辑器](images/rewards-editor-zh-1920.png)

## 2. 搜索范围与筛选

入口：任务搜索框右侧设置图标。搜索范围支持标题、描述、副标题和任务内部内容。
默认勾选标题与描述；面板保持打开，使用底部带关闭图标的按钮结束设置。

![搜索范围多选面板](images/search-scope-zh-1920.png)

筛选界面支持分类、任务组、状态、模板、奖励类型、奖励物品、完成条件类型和目标。
可以同时选择多项，长列表平滑滚动；顶部搜索用于缩小可选项范围。
物品奖励筛选还可以指定具体物品。

![搜索筛选与可滚动选项](images/search-filters-zh-1920.png)

## 3. 完成条件

入口：作者模式 → 任务右键菜单 → 完成条件。
条件树可设置物品、击杀、位置、脚本以及组合条件等。
每行设置目标和数量，组合条件可继续添加子条件；保存只提交条件草稿。

![完成条件编辑器](images/conditions-editor-zh-1920.png)

条件判断、脚本返回值和组合规则详见 [奖励与条件配置](奖励与条件配置.md)
及 [判断节点](trigger-conditions.md)。

## 4. 邮箱与发信

入口：`F8` 或物品栏邮件图标。左侧邮件列表负责选择与筛选，
右侧为发件人、正文及底部附件。未读、收藏、珍藏和附件领取分别保存。

![邮箱列表、邮件正文与附件](images/mailbox-current-zh-1920.png)

新建邮件可用 `F7` 或邮箱发信入口。左侧编辑收件人、发件人、主题和正文，
右侧设置附件、图标、珍藏、有效期、时间基准、头图及跳转。
编辑草稿不会发出邮件，只有点击发送才提交；取消不会发送。

![邮件编辑与发送界面](images/mail-compose-zh-1920.png)

附件使用独立奖励编辑器，可设置物品数量、品质和背景色。
邮件附件与任务奖励共用展示规范，设置后返回邮件草稿。

![邮件附件编辑器](images/mail-attachments-zh-1920.png)

## 5. 战利品

入口：作者工具的战利品表。左侧选择或新建表，右侧配置表名、模式和抽取次数；
每个条目分别设置类型、物品、数量、权重、启用状态、生效条件和物品品质。
权重可输入或拖动滑块；底部保存提交整张表。
多选、撤销与重做用于批量整理和恢复编辑。

![战利品表、权重与品质](images/loot-editor-zh-1920.png)

随机抽取和玩家自选是两种模式。权重控制相对概率，不应把单个条目的权重当成固定掉率。
任务奖励或节点可引用战利品表 ID。

## 6. 旅行历程与任务弹窗

从总览进入旅行历程。顶部切换章节，画布展示章节图标、主线卡片和支线任务。
章节底部标记为白色中心菱形、淡蓝外框与透明光晕。

![旅行历程当前章节与菱形标记](images/journey-chapter-marker-zh-1920.png)

任务卡片不使用悬浮 tooltip 展示整段任务。点击卡片打开详情弹窗，
查看状态、进度、目标和奖励；右上角关闭返回历程，
底部“前往任务界面”才跳转到任务日志。

![旅行历程任务详情弹窗](images/journey-task-details-popup-zh-1920.png)

作者点击铅笔进入编辑模式，右键章节可分别编辑名称、图标、成员、背景和外观。
名称与图标编辑时左侧预览跟随输入更新。

![章节名称与图标编辑](images/journey-chapter-identity-zh-1920.png)

外观编辑使用左预览、右属性布局，只保存当前章节。点击选择控件，
Ctrl 或多选复选框添加选择，全选和反选按钮可批量选择。
拖动内部移动，拖动右侧调宽、底部调高、右下角等比例缩放。
数值、资源、颜色、文字、可见性与预览同步。重置只影响选中的图标或文字。

![当前章节外观、多选与实时预览](images/journey-chapter-multiselect-zh-1920.png)

完整配置和章节切换事件见 [背景与旅行历程参考](background-and-journey-editor.md)。

## 7. 背景与热点事件

热点事件画布可浏览事件卡片、连线和自定义背景；滚轮调整显示比例。
作者可打开背景属性，选择图片/视频、缩放模式、倍率、偏移和背景音乐。

![热点事件界面](images/hot-events-current-zh-1920.png)

背景编辑器左侧直接预览，右侧为可滚动属性；拖动预览移动背景。
支持铺满、自适应、拉伸和原尺寸适配。编辑草稿即时预览，点击完成才保存。
视频仍需要项目的可选媒体后端。

![背景选择、缩放、拖动与音乐](images/hot-background-inspector-zh-1920.png)

事件图中的“更改热点事件背景”节点也有可视化预览入口。
从节点打开、完成编辑后回填该节点草稿，不会在预览时执行服务器动作。

![热点背景节点属性](images/hot-background-node-zh-1920.png)

## 8. 传说人物

传说人物界面提供相关任务入口；作者可编辑人物展示信息。
背景设置与热点事件共用完整编辑器，包含缩放模式、偏移、音乐和素材选择。
这里的背景覆盖保存在当前客户端。

![传说人物界面](images/legendary-current-zh-1920.png)

![传说人物背景实时预览](images/legendary-background-inspector-zh-1920.png)

## 9. 事件图与节点库

入口：任务控件的事件编辑。节点库按事件、判断、动作、变量等用途组织。
选中节点后在右侧设置属性，真/假分支分别连线，不能把视觉上相邻当成已连接。
空白处可拖动框选、平移画布和缩放。

![节点库与分类](images/node-library-current-zh-1920.png)

节点内可选字段直接点击打开菜单，支持中文、拼音和首字母搜索。
长按游戏字段可将它拖成变量节点；玩家数据会显示归属玩家或选择器。

![字段菜单与拼音搜索](images/graph-inline-pinyin-zh-1920.png)

![变量来源与玩家归属](images/graph-variable-owner-zh-1920.png)

脚本等长内容默认完整展示。取消“全部显示”只折叠显示，不截断源码；
双击文字块打开独立编辑器。详见 [节点字段与背包入口](visual-graph-and-inventory-shortcuts.md)。

![节点默认展开的多行脚本](images/graph-full-script-zh-1920.png)

## 10. JavaScript 编辑器

事件图选择 JavaScript 判断后，使用代码图标打开编辑器。
代码、参考和错误信息分别布局；示例可以追加到现有草稿。
保存先检查语法，不会为了预览而执行奖励脚本。

![JavaScript 模式与编辑入口](images/js-predicate-graph-zh-1920.png)

![代码区与字段参考](images/js-editor-reference-zh-1920.png)

![游戏内可选示例](images/js-editor-examples-zh-1920.png)

图内判断最终必须得到布尔 `true`。例如：

```javascript
Number(experienceLevel) >= 10;
```

图内字段是字符串；条件文件中的等级、坐标等是数值。
顶层不能直接写 `return true;`，需要返回的复杂判断使用函数包裹。
类型、异常、真假路径、一次执行和奖励 API 的完整规则见 [JS 文档](javascript.md)。

![语法错误与草稿保留](images/js-editor-syntax-error-zh-1920.png)

## 11. 变量

变量目录将全局与当前任务变量分别展示，支持搜索、名称/时间排序和选择插入。
变量编辑可声明数字或字符串，以及玩家私有或队伍共享。
“全局”表示命名作用域，队伍共享另由共享设置决定。
内置任务进度变量为只读，计算节点不能直接改写进度快照。

![全局和任务变量目录](images/variable-catalog-zh-1920.png)

![数值类型与队伍共享设置](images/variable-editor-zh-1920.png)

计算节点支持加减乘除和常见科学函数；参与数值计算的输入必须是有效数字。
除零、无效数字和非有限结果应检查错误反馈，不会自动当作字符串拼接。

## 12. 图标选择与全屏预览

物品和贴图选择器全屏展示。可以搜索、选择来源和排序，支持正序、倒序，
按 ID、名称或可用的时间信息排列。悬浮项目查看资源 ID、路径及可用的时间信息；
资源包未提供的创建/修改时间不能凭空推断。
点击只选中，底部“应用”才确认。

![全屏物品选择器](images/item-picker-zh-1920.png)

![全屏贴图选择器](images/texture-picker-zh-1920.png)

底部预览打开独立全屏界面。滚轮缩放、拖动平移，双击放大/重置，
底部可适配或重置视图；返回选择器后仍需应用选择。

![图标全屏预览](images/icon-fullscreen-preview-zh-1920.png)

## 13. 富文本与回收站

富文本工具栏作用于当前选区。例如选中文字后点击粗体，
会在选区两侧包裹对应标签。未选择文字时在文末追加格式标签。
左侧源码与右侧渲染预览便于检查标签效果。

![富文本源码、格式工具与预览](images/rich-text-editor-zh-1920.png)

可编辑候选列表提供回收站入口。回收站支持多选、全选和反选，
最终确认后才隐藏选中的候选项；取消不删除。
这里管理的是可编辑候选项，不会卸载物品或删除 Minecraft 注册表内容。

![候选列表](images/value-picker-current-zh-1920.png)

![回收站批量选择](images/suggestion-recycle-bin-zh-1920.png)

## 14. 设置与动画

入口：`/xero_quest open settings`。顶部六个标签切换对应选项，
默认过渡为 100ms。个人偏好与服务器作者配置分别校验权限。
下面六张图分别展示完整标签，较长内容可滚动。

![常规设置](images/settings-general-zh-1920.png)

![动画设置](images/settings-motion-zh-1920.png)

![通知设置](images/settings-notifications-zh-1920.png)

![外观设置](images/settings-appearance-zh-1920.png)

![任务设置](images/settings-tasks-zh-1920.png)

![工具设置](images/settings-tools-zh-1920.png)

动画编辑器包含时间线、关键帧、播放预览和属性。
默认效果只使用缩放与淡化，不包含旋转；自定义时仍可主动设置旋转。
关闭减弱动态后才能观察完整播放效果。

![关键帧动画编辑器](images/animation-editor-current-zh-1920.png)

## 15. 物品栏入口

任务和邮件入口可以分别开关。可视摆放选择九宫格锚点，再拖动设置相对偏移。
左上锚点的 `(0,0)` 表示屏幕左上；右下锚点的偏移相对于右下对齐位置。
安装受支持的 JEI/REI/EMI 时使用对应快捷入口，避免与原生按钮重复显示。

![物品栏入口可视摆放](images/inventory-placement-zh-1920.png)

![物品栏相对锚点实际效果](images/inventory-relative-anchor-zh-1920.png)

![REI 收藏入口示例](images/rei-inventory-shortcuts-zh-1920.png)

## 16. 模板、解锁关系与位置

模板选择器提供模板列表和预览；选择后应用到新任务，再修改任务自己的内容。
模板中的变量进度与结构追踪示例可用于理解节点配置。

![任务模板选择](images/task-templates-zh-1920.png)

解锁图编辑的是任务之间的前置关系，与控件事件图不同。
节点位置和连线可视化展示；保存前应检查循环或无效引用。

![任务解锁关系图](images/unlock-graph-current-zh-1920.png)

地点目标可设置维度、坐标和半径，或选择结构/群系目标。
结构定位产生的坐标与维度应一起保存，跨维度不能只比较三轴数值。

![地点目标编辑器](images/location-editor-zh-1920.png)
