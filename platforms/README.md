# 平台目录

每个加载器和 Minecraft 版本使用独立目录，最终产物也必须独立构建和安装。

```text
platforms/
  fabric/
    1.21.1/
    26.1/
    26.2/
    26.3/
  forge/
    1.20.1/
  neoforge/
    1.21.1/
    26.1/
    26.2/
    26.3/
```

共享任务模型、存档格式、资源和 UI 逻辑保留在 `src/main`。平台目录只放入口点、
事件桥接、网络注册、注册表和加载器元数据，避免多个 JAR 互相覆盖。

当前已迁移目录：

- `neoforge/1.21.1`：现有完整 NeoForge 构建入口。
- `fabric/1.21.1`：Fabric 平台服务与元数据骨架。

其他目录由迁移任务逐步启用，不会被默认构建误打包。
